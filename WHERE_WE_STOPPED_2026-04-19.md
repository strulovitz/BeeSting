## 📌 Key lessons learned today (applied to all future shots)

All in `HANDOFF_VIDEO_PRODUCTION.md`, lessons 10 through 22:

- **10:** Always read the reference PNG before writing the Kling prompt (credits).
- **11:** Always remind Nir to import to Premiere after every clip.
- **12:** COPY files from Downloads to repo, NEVER MOVE — Nir drags from Downloads into Premiere.
- **13:** Minimal announcements — scene # + 2-3 word description + critical param only.
- **14:** Never say "OpenArt" — name the specific engine (ChatGPT Image 1.5 / Kling 3.0 Omni / Kling Avatar / Veo 3.1).
- **15:** Aspect ratio is set in the GUI, never in the prompt text.
- **16:** Reference images are 1:1 1024×1024 (for Kurzgesagt mechanism shots); 3:2 for the S15 freeze frame to match Kling 16:9 clips; 16:9 for Kling video clips.
- **17:** Never describe subjects as getting larger/closer/clearer — Kling inflates them literally.
- **18:** Kling drops ANY unnamed scene element (HUD, backgrounds, props, doors, maps) — re-describe every persistent element in every Kling prompt.
- **19:** Avoid vague motion words like "tick" / "flicker" — Kling interprets them as blinking. Be concrete: "counts up one second at a time."
- **20:** Every Kling prompt MUST include explicit camera motion. "Hovers" / "holds" / "static" = wasted credits.
- **21:** Never ask Kling to animate text appearing/changing on screen — it writes gibberish. Use icons or static pre-rendered text.
- **22:** Queen + worker + amber + crown = ChatGPT draws a literal bee. Always include explicit anti-bee clause + mechanical quadcopter description.
