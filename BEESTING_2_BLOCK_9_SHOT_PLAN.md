## Core principles — Kling is NOT Hollywood (read `KLING_NOT_HOLLYWOOD.md` before any prompt)

1. **ONE real motion per scene.** Glides, drives, drops, fans, scrolls, sweeps, dissolves, intensifies. NO chained motions. NO "and then." NO "while also." If a Kling prompt has two verbs acting on two different objects, it is wrong.
2. **Reference image = the scene's composition and key elements in place.** Kling adds the ONE motion. Never animate text. All labels frozen in the PNG.
3. **Symbolize, don't write.** Concepts = icons. Allowed text in visuals: NSA, BIG AI, PRIVATE MODE, TOP SECRET. Block 9 also allows the small in-scene labels: TRAINING, ONE-TIME PURCHASE, MEDICAL AI VENDOR, TEACHER, STUDENT, DISTILLATION, MELANOMA-SPECIALIST.MODEL, MELANOMA.MODEL, HEART-SOUND.MODEL, CHEST-XRAY.MODEL, PATHOLOGY.MODEL, SAME TRICK, ONE BILL, THE HIVE, TRAINED ON, NEVER USED, SAME PHOTO DIFFERENT EYES, MELANOMA — STAGE II, FUZZY GENERIC BLOB — USELESS, CLOUD AI FOR HOSPITALS, NYC HOSPITALS CANCEL PALANTIR, MARCH 2026 — IN-HOUSE, PATIENT RECORD, NAME, DOB: 1947-08-12, DIAGNOSIS: METASTATIC MELANOMA, JANE M. DOE, BIG DATA ENGINE.
4. **No real Big AI names.** OpenAI / Google / Anthropic / xAI / ChatGPT / Claude / Gemini / Grok / Microsoft / Meta = forbidden. **BIG AI** = allowed. **PALANTIR** = allowed in S10 only (carve-out).
5. **Faces are real.** Every cartoon person has clothing + hair + expression + posture. NEVER the egg-formula. Vampire (S9) is the only intentional faceless silhouette.
6. **Camera varies every clip.** S1 push-in → S2 static wide → S3 pull-back → S4 pan-right → S5 tilt-up → S6 static centred → S7 push-in → S8 close hold → S9 push-in → S10 pull-back wide. **No two consecutive shots share a camera move.** ✓
7. **Kling settings:** 3.0 Omni, 720p, 6s, Native Audio OFF, reference image mode.
8. **One clip at a time.** Never batch.
