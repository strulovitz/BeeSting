## Core principles — Kling is NOT Hollywood

1. **ONE real motion per scene.** Something physical that actually MOVES — slides, drops, presses, streams, splits, pulses outward. NO "glow / shimmer / twinkle" filler. NO chained motions.
2. **Reference image = the scene's composition and key elements in place.** Kling adds the ONE motion. Never animate text. All labels frozen in the PNG.
3. **Symbolize, don't write.** Concepts = icons. Only allowed text in visuals: NSA, BIG AI, PRIVATE MODE, TOP SECRET. Block 8 also allows the small in-scene labels: "MY SON", "VOICE CLONE", "EVERY FACE", "EVERY VOICE", "OVERVIEW", "SUSPECT".
4. **No real Big AI names.** OpenAI / Google / Anthropic / xAI / ChatGPT / Claude / Gemini / Grok / Microsoft / Meta = forbidden. BIG AI = allowed.
5. **Faces are real.** Every cartoon person has clothing + hair + expression + posture. NEVER "round head + dot eyes + line mouth" — that produces eggs. See `BEESTING_2_BLOCK_7_FACES_BRIEFING.md` for the full warning.
6. **Camera varies every clip.** S1 push-in → S2 static wide → S3 pull-back → S4 pan-right → S5 static centered → S6 tilt-down → S7 push-in → S8 static medium → S9 pull-back wide → S10 close static. No two consecutive shots share a camera move.
7. **Kling settings:** 3.0 Omni, 720p, 6s, Native Audio OFF, reference image mode.
8. **One clip at a time.** Never batch.
